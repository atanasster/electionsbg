Call 2 - Competitive call for project proposals dedicated to Priority 2: A Green Region, Specific Objectives 2.4 and 2.7

Launching date: 10th of May 2023

The call was closed on September 11, 2023.

  • Please see CORRIGENDUM and use the revised versions for Annex A1 Project Statement, Annex A 2 Project partner statement and Annex A 10 Financial Capacity Self-Assessment.

The Applicant's Guide for the competitive call for projects dedicated to Priority 2: A Green Region, Specific Objectives 2.4 and 2.7, financed by Interreg VI-A Romania-Bulgaria Programme:

  • Corrigendum 26.07.2023 to the Applicant's Guide
  • Applicant's Guide (main document)
  • Annexes to the application form for which a standard format exists
    • Annex A1 Project statement (Revised 26.07.2023)
    • Annex A1 Project statement
    • Annex A2 Project partner statement (Revised 26.07.2023)
    • Annex A2 Project partner statement
    • Annex A3 State-aid self-assessment
    • Annex A7 DNSH declaration
    • Annex A8 Associated partner declaration (if applicable)
    • Annex A10 Financial Capacity Self-Assessment (Revised 04.08.2023)
    • Annex A10 Financial Capacity Self-Assessment

In the preparation process of the application form, please have in mind the following documents, as part of the Applicant's Guide:

  • Annex A Evaluation grids
  • Annex B List of eligible expenditure
  • Annex C Methodologies for using lump sums for project preparation and project closure within the Interreg VI-A Romania-Bulgaria
  • Annex D Complaint procedure for evaluation results
  • Annex E SEA mitigation measures and indicators
  • Annex F Template Framework subsidy contract
  • Annex F Milestones for the activities_indicators
  • Annex G Template co-financing contract
  • Annex G Template RO monitoring agreement
  • Annex H Template Partnership Agreement
  • Annex I DNSH Interreg VI-A Romania-Bulgaria level
  • Annex J Relevant national and EU legislation
  • Annex K.1 Application form_2.4+.2.7 (off-line format)
  • Annex K.2 Application form_ Budget (off-line format)

Relevant documents to be considered when developing the application form:

  • Guidance on monitoring Programme indicators for Interreg VI-A Romania-Bulgaria
    • Guidance on monitoring Programme indicators_Annex 2_SO 2.4
    • Guidance on monitoring Programme indicators_Annex 3_SO 2.7
  • Communication Starter Kit
  • Manual for Visual Identity of the Programme (drafting ongoing)
  • Go Green!
  • Code of Conduct for Interreg VI-A Romania-Bulgaria
  • Practical guide on fraud for applicants and project partners
  • JEMS manual - https://jems.interact.eu/manual/.

The application forms should be submitted only in electronic format, via electronic system Jems, which can be accesed here: https://jems-robg.mdlpa.ro/

The call deadline for submitting the applications in Jems is 11th of September 2023, 12.00 (PM).
