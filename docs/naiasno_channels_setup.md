# Наясно — opening the seven channels

Operator runbook for reserving and setting up `naiasno` on YouTube, TikTok, Instagram,
LinkedIn, X, Pinterest and Telegram. Companion to `docs/plans/naiasno-rebrand-v1.md`
(§10 decides *which* channels get staffed; this file is *how* to open them) and to
`docs/naiasno_facebook_launch.md` (the Facebook page and group, already live).

**All seven handles were verified free on 2026-08-09.** Re-check before claiming.

---

## 0. Do this before opening a single account

**Reserve first, decorate later.** The handles are the perishable part; the artwork is
not. If time is short, claim all seven names in one sitting with nothing but the avatar,
and come back for banners and bios.

**Do not open any channel with the naiasno.bg URL in it.** The domain is mid-заявка and
does not resolve. Every "website" field below takes `https://electionsbg.com` today; the
flip's 301s will carry those links afterwards, and the bios get updated in the same pass
that changes the site.

**Only three of the seven get staffed** — YouTube, Instagram and LinkedIn. TikTok waits
for a batch of 4-6 shorts; Pinterest and X are handle reservations. Telegram is a channel
shell. An empty, well-branded profile reads as "new"; a profile with three posts and then
six months of silence reads as abandoned, which is worse than nothing.

## 1. The assets

Generated by `npm run brand:channels` → `brand/channels/`. Regenerate any time; it is
procedural, needs no API key and no network.

They are **committed**, unlike `brand/posts/` and `brand/videos/` — `.gitignore` draws
that line deliberately ("the rest of brand/ (covers, ads, profile artwork) stays
tracked"), and these are profile artwork in the same class as `brand/profile_1080.png`.

| Platform | Avatar | Banner |
|---|---|---|
| YouTube | `avatar_youtube_800.png` | `banner_youtube_2560x1440.png` |
| TikTok | `avatar_tiktok_800.png` | — |
| Instagram | `avatar_instagram_1080.png` | — |
| LinkedIn | `avatar_linkedin_400.png` | `banner_linkedin_1128x191.png` |
| X | `avatar_x_400.png` | `banner_x_1500x500.png` |
| Pinterest | `avatar_pinterest_800.png` | — |
| Telegram | `avatar_telegram_1280.png` | — |
| any (alternative) | `avatar_wordmark_1080.png` | — |

**The avatars are the "на" monogram, not the wordmark, and that is deliberate.** An
avatar is seen at 32-100px almost everywhere that matters. Six Cyrillic letters at that
size are a smudge. `avatar_wordmark_1080.png` is the alternative for whoever prefers
exact sameness with the current Facebook profile picture — that is a real trade (brand
consistency vs legibility) and it is the operator's call, but the monogram is the
recommendation.

Two constraints are baked into the generator, and both are the kind that only show up
after upload:

- **Every avatar is circle-cropped.** Content sits inside the inscribed circle; nothing
  goes in a corner.
- **Banners have safe zones far smaller than the image.** YouTube shows only a centred
  1235×338 of its 2560×1440 on a phone; X puts the avatar over the lower-left of the
  header; LinkedIn's page logo covers the left ~220px of the cover. The banner builder
  sizes its text block to fit the safe rect and **throws** if it would overflow — the
  first draft put YouTube's tagline 24px and its kicker 84px below the window, i.e.
  invisible on the surface where the channel is actually seen.

## 3. YouTube — the one with an irreversible decision in it

This is the only channel with content ready today: the risk-analysis explainer is
rendered and waiting in `brand/videos/2026-08-09-election-risk-explainer/`.

1. **Create the channel on a Brand Account, not a personal Google account.** A personal
   channel cannot be transferred and cannot have co-managers. Converting later is
   possible but messy. Do this right at creation: YouTube → Settings → Add or manage your
   channel(s) → **Create a channel** (this creates a Brand Account channel), *not* the
   "use your name" path.
2. Channel name `Наясно`; handle `@naiasno` (these are two separate fields — set both).
3. **Verify by phone** (Settings → Channel → Feature eligibility). This unlocks custom
   thumbnails and uploads over 15 minutes. The first explainer is 12:44, so it fits
   either way — but the next one will not, and the thumbnail matters immediately.
4. Avatar and banner from the table above. Skip the video watermark for now.
5. Channel description: the long-form bio. Add links to the site, the Facebook page and
   the Facebook group (Customise channel → Basic info → Links).
6. Defaults (Settings → Upload defaults): language **Bulgarian**, category **News &
   Politics**, "not made for kids".
7. **Upload the explainer** — title, description and tags verbatim from that folder's
   `draft.md`. Attach `captions.vtt` as the Bulgarian subtitle track (do not rely on
   auto-captions; the `.vtt` is derived from the signed-off script and cannot
   mis-transcribe). Custom thumbnail `thumb.png`. Add chapters to the description —
   59 scenes over 12:44 needs them.
8. Record the channel URL and video ID; set `status: "published"` in
   `brand/videos/index.json`.

## 4. Instagram — cheapest reach in the set

1. Create the account as **Professional → Business** (not Creator, not personal).
2. Handle `naiasno`, name `Наясно`, avatar, short bio, website.
3. **Link it to the existing Facebook Page in Meta Business Suite.** This is the whole
   point: it is what turns Page→Instagram cross-posting into a settings toggle. A
   personal account claims the handle and gets you none of the workflow.
4. The square cards in `brand/posts/` are already 1080×1080 — the existing back catalogue
   is postable as-is.

---

## 5. LinkedIn — small effort, multiplier audience

1. A **Company Page** requires a personal LinkedIn profile as its creator/admin.
2. Page name `Наясно`, public URL `linkedin.com/company/naiasno`, logo
   `avatar_linkedin_400.png`, cover `banner_linkedin_1128x191.png`.
3. Industry: *Civic and Social Organization* or *Information Services*. Website, tagline,
   long-form bio; add the English bio as the secondary locale.
4. **Add a second admin immediately.** A page with one admin is one lost account away
   from unrecoverable, and LinkedIn's recovery path for orphaned pages is slow.

## 6. TikTok — claim now, post later

1. Claim `@naiasno`, set the avatar and the short bio. **The username can only be changed
   once every 30 days**, so get it right first time.
2. Switch to a **Business account** (Settings → Account → Switch to Business Account) —
   it gives analytics and a bio link.
3. **Then stop.** Per the plan, TikTok opens properly only once 4-6 shorts exist as a
   batch, because the platform punishes irregular posting. One render from
   `naiasno-video`'s SHORT format feeds TikTok, Instagram Reels, Facebook Reels and
   YouTube Shorts.

## 7. X and Pinterest — reservations

**X:** claim `@naiasno`, set name, avatar, header, short bio, website. Post nothing.

**Pinterest:** create a **Business** account, claim `naiasno`, avatar, long bio. Skip
"Claim your website" for now — that wants a domain you control and the `.bg` is still
mid-registration; revisit after the flip if Pinterest is ever staffed.

---

## 8. Telegram — a channel, not an account

1. In Telegram: **New Channel** (not a group, not your personal username).
2. Name `Наясно`, description = long-form bio, photo `avatar_telegram_1280.png`.
3. Set the **public link** to `t.me/naiasno`.
4. **Claim the username for the channel, not for a personal account.** A Telegram
   username belongs to exactly one entity; spending `naiasno` on a personal account burns
   the public link the project wants. Note Telegram reclaims usernames left inactive, so
   this one is not fire-and-forget.

## 9. After all seven exist

- Record every URL in `src/lib/community.ts` (and its `ai/app/community.ts` twin), which
  is already the single source of truth for the Facebook destinations. Not inline in the
  footer or the About page.
- Add the channel URLs to the Organization JSON-LD's `sameAs` array in
  `scripts/prerender/jsonLd.ts` — that is how Google learns the entity under the new name
  is the same entity, which is load-bearing for the domain migration.
- Add YouTube (and any other staffed channel) to the footer and the About page's channels
  row.
