### Conclusion
Single-threaded (139-150ms for ~22.3k buffers, all cache hits) is still slower per buffer
touched than the Enterprise Plus baseline's 2-worker parallel run (99ms for ~23.9k buffers,
all cache hits). Ratio of buffer-normalized time: baseline ~4.1us/buffer (2 workers
overlapping) vs this single-threaded run ~6.2-6.7us/buffer. Parallel-worker overhead alone
cannot explain a gap of this size when the serial case is already slower than the old
parallel case handling a comparable buffer count. Points to a genuine per-core throughput
difference between the two machine classes, not (only) coordination/dispatch cost.
